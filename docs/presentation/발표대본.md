# KNIGHT / SLIMES 발표 대본 초안

- 본문 5장, 권장 시간 배분 합계 **110초**입니다.
- 시간은 배분안이지 실측 발화 시간이 아닙니다. 2분 이내인지 직접 리허설해야 합니다.
- 플레이테스트 영상 하이퍼링크를 연결했습니다. 파일 삽입·자동 재생은 하지 않습니다. 재생할 경우 보스전 설명을 대체해 전체 시간을 유지합니다.
- 화면 이미지는 검증용 배치에서 실제 게임 렌더러가 출력한 장면입니다.

## 1. KNIGHT / SLIMES — 0~10초

안녕하세요, 최익진입니다. 적을 이동 재료로 활용하는 2D 퍼즐 액션 게임, 나이트 슬라임즈를 만들었습니다.

**발표자 메모**: 타이틀은 짧게 소개하고 바로 다음 장으로 넘깁니다. 이미지들은 실제 렌더러의 검증용 배치 화면입니다. 플레이테스트 영상은 마지막 장의 링크에서 열 수 있습니다.

## 2. 세 공간, 세 가지 진행 — 10~35초

1스테이지는 가로 진행과 상하 중력 반전, 2스테이지는 세로 등반과 좌우 순환입니다. 마지막은 사방이 연결된 보스방입니다. 지형과 적 구성이 달라지며, 카메라도 진행 방향을 추적합니다. Esc로 일시정지할 수 있습니다.

**발표자 메모**: 요구사항 A·B·D를 묶어 설명합니다. 3스테이지는 한 화면이라 카메라 고정이고, 1·2스테이지에서 각각 X/Y 이동 카메라를 확인할 수 있습니다. 각 단계는 맵과 동적 오브젝트 구성이 다릅니다.

## 3. 전투를 퍼즐로 바꾸는 세 가지 규칙 — 35~60초

첫째는 속도를 보존하는 중력 반전 포털입니다. 둘째는 원본에서 분신을 만들고 시체를 벽돌로 쓰는 규칙입니다. 셋째는 시간을 멈춰 위치를 확인한 뒤 분신을 움직이는 퍼즐입니다. 적을 처치 대상이자 이동 자원으로 만들었습니다.

**발표자 메모**: 요구사항 C의 코드 기반 요소 세 가지입니다. 구현 근거는 StageModel의 physics, handleEnemyBoundaries, selectBossTarget, updateEchoTarget입니다. 이미지 변경 자체를 독창 요소로 세지 않습니다.

## 4. 분신을 표적으로 보내면 보스가 열린다 — 60~90초

보스전은 이 규칙을 합친 공간입니다. 시간을 멈추면 표적이 보입니다. 정지가 풀린 뒤 일반 공격으로 분신을 표적에 밀어 넣어야 보스가 노출됩니다. 공격 순간에 맞춘 방어, 저스트 패리로 봉인 하나를 깹니다. 매번 새 표적과 새 전달이 필요하고, 세 봉인을 깨면 승리합니다.

**발표자 메모**: 정지 중에는 밀치기와 패리가 불가능합니다. K 유지 방어와 새 입력의 저스트 패리를 구분합니다. 시연 영상을 넣는다면 이 장의 긴 설명을 짧은 실제 플레이 장면으로 대체하고 총 발표 시간을 다시 맞춥니다.

## 5. 규칙은 모델에, 화면은 렌더러에 — 90~110초

규칙과 화면을 분리해 120헤르츠 고정 틱으로 처리했고, 24개 캠페인과 실행 파일을 검증했습니다. 완주 후 N으로 새 게임을 시작할 수 있습니다. 소스와 실행 파일은 공개 저장소에 있습니다. 감사합니다.

**발표자 메모**: 자동 입력 검사는 도달 가능성과 결정성의 검증입니다. 초보자 난이도나 모든 예외 상황이 검증되었다고 말하지 않습니다. 최종 승리 화면의 N은 전체 새 게임, R은 현재 단계 재도전입니다. 플레이테스트 영상 링크가 연결되어 있으며 자동 재생하지 않습니다.
