# Paradox Warden 이미지

## 시트 계약

`assets/art/paradox_warden/sheet.png`는 288×192 RGBA8 시트입니다. 96×96 셀을 3열·2행으로 배치하며 `manifest.json`의 `paradox_warden` 그룹을 사용합니다.

| 인덱스 | 클립 | 상태 |
|---|---|---|
| 0 | `sealed` | 닫힌 금색 흉갑 |
| 1 | `exposed` | 열린 장갑과 청록 코어 |
| 2 | `charge` | 들어 올린 팔과 앰버 충전 |
| 3 | `attack` | 적색 집중 코어 |
| 4 | `break` | 장갑 결손·균열·파편 |
| 5 | `defeated` | 낮게 무너진 갑옷 |

각 클립은 정적 한 프레임입니다. 부드러운 중간 동작이나 광선 텍스처를 포함하지 않습니다. 모델이 전투 상태와 광선 판정을 결정합니다.

## 앵커와 입력

셀 원점은 `(48,90)`입니다. 런타임 192×192 표시에서는 `(96,180)` 오프셋을 사용합니다. 프레임별 바운딩 박스에 맞춰 확대하지 않으며 서 있는 상태들의 발 레이어를 고정합니다.

`assets/art/paradox_warden/source.png`는 처리 입력이며 런타임에서는 로드하지 않습니다. 1024×576 입력의 X 분할은 `0,341,683,1024`, Y 분할은 `0,288,576`입니다. 빌더가 매트 제거·팔레트 정리·고정 배율 정렬을 수행합니다. 시트 좌표·알파 경계·해시는 manifest를 기준으로 합니다.

## 명령

```sh
python tools/build_boss_assets.py
python tools/test_boss_assets.py
```

검사는 PNG·CRC·프레임 좌표·상태별 픽셀 차이·발 기준·알파 경계·해시·재빌드 일치를 다룹니다. 실제 표시와 노출 규칙은 [런타임 에셋](RUNTIME_ASSETS.md), [보스전](STAGE3_BOSS.md)을 참고하세요.
