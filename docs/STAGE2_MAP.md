# 2스테이지 — Lateral Ascent

## 지도

1280×2560 세로 탑입니다. 카메라는 등반을 따라가며 좌우 경계가 연결됩니다. 좌우 포털은 높이·중력·속도를 유지합니다. 색상은 높이와 무관하게 x640을 기준으로 왼쪽 따뜻한 색, 오른쪽 청록색입니다.

| 구간 | 주요 배치 |
|---|---|
| y40–440 | 서쪽 지그재그 계단, 원본 `(10,440)` |
| y440–600 | 동쪽 수신 발판 x1000–1280, 복제체 단차 |
| y680–1040 | 동쪽 테라스와 상층 우측 포털 진입부 |
| y1000–1740 | 서쪽 수신 발판과 지그재그 계단 |
| y1840–2360 | 정상 테라스와 출구 `(600,2340,100,130)` |

정확한 충돌 사각형은 [StageTwoLevel.java](../core/src/main/java/io/jbnu/test/StageTwoLevel.java)에 있습니다.

## 진행

1. 서쪽 계단을 올라 원본을 왼쪽 경계 밖으로 밀고, 동쪽에 생긴 복제체를 따라갑니다.
2. L로 동쪽 표적 위치를 기억합니다. 후보 중심 X는 1050·1120·1200, Y는 440이며 크기는 88×44입니다. 표적은 정지 중에만 보입니다.
3. 정지 해제 후 살아 있는 정상 중력 복제체를 표적 밖에서 안으로 유도해 정적 발판 위에 세웁니다. 이 조건으로 출구가 영구 해제됩니다. 정지 중 복제체 배치나 단순 공중 통과는 완료되지 않습니다. J 전달이 필수인 보스전과 다릅니다.
4. 복제체를 다시 고정해 높은 동쪽 선반에 올라갑니다. 테라스를 오른 뒤 우측 경계로 넘어 서쪽 상층 수신 발판에 착지합니다.
5. 서쪽 계단과 정상 테라스를 따라 열린 출구에 닿습니다. Enter로 3스테이지에 진입합니다.

착지 없이 연속 두 번 경계를 넘으면 사망합니다. R 재시작은 이 탑의 시작으로 돌아갑니다.

## 검사

`EchoTargetTest`는 표적·문 조건을, `StageModelTest`와 `EchoRouteTest`는 수평 포털·복제체 발판·입력 경로·캠페인을 검사합니다. `python tools/model_test.py`로 실행합니다. 위치별 화면은 `python tools/render_smoke.py --scene stage2top`처럼 확인할 수 있습니다.
