# 에셋 출처와 사용 범위

이 문서는 프로젝트 리소스의 처리 입력과 사용 범위를 구분합니다. 코드와 에셋 전체에 임의의 단일 라이선스를 부여하지 않습니다.

## 이미지

- 기본 캐릭터·슬라임·효과·지형의 입력 파일은 `assets/art/source/`와 각 처리 도구의 입력 경로에 보관합니다. 알려진 원본 이미지 URL과 처리 과정은 [픽셀 처리 문서](PIXEL_ASSET_PIPELINE.md), [에셋 목록](ASSET_BRIEF.md), 각 manifest에 기록되어 있습니다.
- 최종 보스의 `assets/art/paradox_warden/source.png`는 이미지 생성 도구의 출력물을 입력으로 사용했습니다. `tools/build_boss_assets.py`가 매트 제거, 배율·앵커 정렬, 장갑·코어 상태 편집을 수행해 전용 시트를 만듭니다.
- 소스 해시, 파생 시트 좌표, 프레임별 상태와 앵커는 manifest 및 [보스 문서](BOSS_ART.md)에 남겨 두었습니다. 원본을 임의의 직접 촬영·수작업 원화라고 표시하지 않습니다.
- 원본 이미지별 생성 모델·서비스의 구체적인 사용 조건과 별도 권리 증빙은 모두 확인된 상태가 아닙니다. 따라서 공개 재배포나 상업적 재사용이 가능하다고 보증하지 않습니다. 필요 시 원본 서비스의 조건을 별도로 확인해야 합니다.

## 효과음

효과음 30개는 `tools/generate_sfx.py`의 로컬 합성기로 만듭니다. WAV 목록과 처리 방식은 [효과음 문서](AUDIO_PACK.md)에서 확인할 수 있습니다.

## 외부 라이브러리

LibGDX, LWJGL, Gradle Wrapper 등 외부 구성요소에는 각 프로젝트의 라이선스가 적용됩니다. 원래의 저작권·라이선스 표시를 삭제하거나 이 프로젝트의 독자 저작물로 표시하지 않습니다.

## 저장소와 실행 배포의 차이

원본·출처 기록은 재현과 확인을 위해 소스 저장소에 유지합니다. 실행 JAR에는 런타임 시트·배경·효과음 등 필요한 리소스만 포함하며, 처리 입력·미리보기·검증용 proof 파일은 제외합니다. 현재 저장소는 과제 검토용 공개 저장소입니다. 공개 설정은 원본 에셋별 사용 조건의 확인을 대신하지 않습니다.
