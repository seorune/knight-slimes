# 1스테이지 — Boundary Foundry

## 지도

4200×720 가로 맵입니다. 상하 경계 통과 시 중력이 반전되며 아래쪽은 따뜻한 색, 위쪽은 청록색입니다. 좌표는 좌하단 기준 `(x,y)`입니다.

| 구간 | 주요 배치 |
|---|---|
| x0–520 | 바닥과 높이 140·240의 출발 계단 |
| x780–1520 | y540 선반, y680 천장 지형 |
| x1520–2200 | 하부 수신 바닥, x1850부터 높은 단차 |
| x2200–3050 | 원거리 전투 구간 |
| x3050–4200 | 높이 190의 출구 선반 |

천장 원본은 `(1410,636)`, 중력 `+1`입니다. 원거리 원본은 `(2780,40)`에 있습니다. 출구는 `(4050,190,100,130)`입니다. 전체 충돌 배치는 [StageOneLevel.java](../core/src/main/java/io/jbnu/test/StageOneLevel.java)에 있습니다.

## 진행

1. 출발 계단을 넘고 낙하 속도를 유지해 상하 포털을 통과합니다. 역중력으로 차가운 선반과 천장에 접근합니다.
2. L로 하부 표적 위치를 기억합니다. 표적 후보 중심 X는 1660·1730·1790, Y는 40입니다. 88×44 표적은 시간 정지 중에만 보이며 해제 후에도 같은 위치를 유지합니다.
3. 정지 해제 후 천장 원본을 경계 밖으로 밀어 하부에 복제체를 만들고 따라갑니다. 같은 중력의 살아 있는 복제체를 표적 밖에서 유도해 정적 바닥 위 표적에 서게 하면 출구가 열립니다. 추적 유도도 유효하며 새 J 적중을 요구하지 않습니다.
4. 복제체를 시간 정지로 고정해 높은 단차를 넘습니다. 원거리 전조 뒤 공격에 저스트 패리하면 원본이 벽돌로 변합니다. 벽돌을 밀어 다음 단차의 발판으로 사용할 수 있습니다.
5. 열린 출구에 닿으면 클리어하고 Enter로 2스테이지에 진입합니다.

포털 사이에는 실제 착지가 필요합니다. 살아 있는 원본 탑승은 정지 해제와 패리 불가 상단 공격을 유발합니다. 공통 조건은 [게임 규칙](STAGE1_RULES.md)을 참고하세요.

## 검사 위치

`StageModelTest`, `EchoTargetTest`, `EchoRouteTest`는 규칙, 표적·문, 입력 경로와 연속 캠페인을 검사합니다. 입력 기록은 테스트 코드에 보관하며 지도 문서에 복사하지 않습니다.
