# 3스테이지 — Paradox Warden

## 봉인 해제

보스는 세 봉인을 가집니다. 봉인마다 다음 순서를 반복합니다.

1. **L / MARK**: 시간 정지가 유지되면 도달 가능한 지지면에 무작위 표적을 만듭니다. 원본 탑승으로 즉시 취소된 정지는 표적을 만들지 않습니다.
2. **WAIT**: 자연 해제를 기다립니다. 표적은 해제 후에도 보이며, 대기 중 L을 다시 써도 재추첨되지 않습니다.
3. **J / PUSH**: 표적 생성 후 정지가 풀린 상태에서 새 J를 살아 있는 복제체에 실제로 적중시킵니다. 넉백이 유지되는 동안 같은 중력의 복제체 중심이 표적 X 범위에 들어오고 몸체가 겹치면 보스가 노출됩니다. 공중 통과도 유효하며, 이미 표적 안에 들어온 복제체에 새 J를 적중시켜도 인정합니다. 표시는 실제 64×60 판정 영역과 같은 좌표·크기로 그립니다.
4. **K / PARRY**: 보스 광선에 새 저스트 패리를 성공시키면 봉인 하나와 해당 표적·노출 충전을 소비합니다. 마지막 봉인은 즉시 승리입니다.

노출은 봉인을 소비할 때까지 유지되며 시간 만료가 없습니다. 단순 추적·복제체 탑승·과거 넉백·원본·시체·다른 중력·정지 중 J는 노출 조건이 아닙니다. 일반 방어는 공격만 막습니다. 노출 전 저스트 패리도 부상 해제와 짧은 무적은 주지만 봉인을 깨지 못합니다. 저스트 재시도에는 K를 떼었다가 타이밍에 맞춰 다시 눌러야 합니다.

## 지도와 표적

- 1280×720, 상하·좌우 포털. 좌우는 높이·중력·속도를 유지하고 상하는 속도를 유지하며 중력을 반전합니다. 실제 착지 없는 두 번째 포털 통과는 사망입니다. 모서리는 X축 우선입니다.
- 바닥·천장의 좌우 받침은 x0과1060, 폭220, y0과680, 높이40입니다. 중앙 받침은 `(420,210,160,20)`, `(700,490,160,20)`입니다.
- 원본은 바닥 왼쪽 `(15,40, gravity=-1)`과 천장 오른쪽 `(1220,636, gravity=+1)`에 있습니다. 둘 다 순찰·상단 반격·복제·벽돌 부활 규칙을 따릅니다.
- 표적은 64×60입니다. 바닥 표적 Y는40, 천장 표적 Y는620입니다. 지지면 내부에서 위치를 추첨하며 기존 복제체와 처음부터 겹치거나 직전과 같은 위치는 제외합니다. 적합한 후보가 없으면 표적을 만들지 않습니다.

## 공격과 모델 계약

보스는 0.8초 전조 때 플레이어 높이와 좌우 방향을 고정하고 0.18초 동안 수평 광선을 활성화합니다. 회복은 1.2초, 다음 대기는 0.7초입니다. 광선은 정적 벽·월드 끝에서 막히고 포털을 통과하지 않습니다. 몸 접촉이나 J로 보스를 처치할 수 없습니다.

공유 상태는 `echoTarget`, `targetRevealed`, `targetSolved`, `targetGravity`, `targetVersion`입니다. 보스 전달은 현 표적 세대의 실제 J 적중과 남은 넉백을 검사합니다. `boss.primed`와 `exposure`는 소모형 노출 상태이며 카운트다운이 아닙니다. 1·2스테이지의 출구 잠금은 별도 조건입니다.
