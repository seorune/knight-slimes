# 공통 게임 규칙

## 이동과 포털

좌표는 오른쪽·위쪽이 양수이며 모델은 120Hz로 진행합니다. `gravity=-1`은 바닥 방향, `+1`은 천장 방향입니다. 점프는 현재 중력의 반대 방향입니다.

- 1스테이지: 4200×720, 상하 포털. 2스테이지: 1280×2560, 좌우 포털. 3스테이지: 1280×720, 양축 포털.
- 좌우 포털은 높이·중력·부호 있는 속도를 유지합니다. 상하 포털은 X·부호 있는 속도를 유지하며 중력을 반전합니다.
- 모서리 동시 이탈은 한 틱에 X축을 우선 처리합니다.
- 플레이어는 실제 착지 없이 두 번째 포털을 통과하면 즉사합니다. 정적 지형·복제체·벽돌 지지면에 실제 착지하면 횟수가 초기화됩니다. 무적·방어·겹침 보정은 착지를 대신하지 않습니다.

## 전투와 시간

- J는 0.28초 동작 중 0.07초 선행 동작 뒤 한 번 넉백을 적용합니다. 피해나 처치는 없습니다.
- K를 누르는 동안 일반 방어를 유지합니다. 첫 0.08초의 저스트 패리는 일반 적을 처치하고 부상을 해제하며 0.45초 무적을 줍니다. 누른 채로 저스트 창이 반복되지는 않습니다.
- 일반 패리는 적을 기절시킵니다. 원거리 공격도 시전자를 대상으로 판정합니다.
- 활성 공격만 피해를 줍니다. 몸 접촉은 안전하지만 몸체를 옆으로 관통할 수는 없습니다. 첫 피격 후 5초 안에 다시 유효 타격을 받으면 사망하며, 추가 피격 없이 시간이 지나면 회복합니다.
- L은 3초 시간 정지, 해제 후 4초 쿨다운입니다. 정지 중 적 넉백·패리·기절·처치는 불가능합니다. 기존 활성 공격 박스는 계속 위험합니다. Esc 일시정지는 플레이어를 포함한 모든 타이머를 멈춥니다.

## 원본·복제체·벽돌

원본은 순찰하고 살아 있는 복제체는 플레이어를 추적합니다. 살아 있는 원본을 밟으면 시간 정지가 해제되고 패리할 수 없는 상단 공격이 발동합니다. 복제체와 벽돌은 안전한 발판입니다.

원본을 산 채로 경계 밖으로 밀면 최초 위치로 복귀하고 반대편에 복제체를 만듭니다. 원본당 복제체는 하나이며 새 복제체가 기존 것을 대체합니다. 원본 처치 시 44×22 벽돌이 남고, 벽돌이 경계를 넘으면 원본이 반대편에서 부활합니다. 복제체는 처치되거나 경계를 넘으면 벽돌 없이 소멸합니다.

## 표적과 진행

1·2스테이지는 시간 정지 중에만 표적을 보여 줍니다. 해제 뒤 같은 중력의 살아 있는 복제체가 표적 밖에서 들어와 정적 지지면 위에 안정적으로 서면 출구가 영구 해제됩니다. 이 전달에는 J 적중이 필수가 아닙니다. 정지 중 배치·원본·시체는 완료 조건이 아닙니다.

3스테이지는 [보스 전용 전달 조건](STAGE3_BOSS.md)을 사용합니다. 클리어 후 Enter는 다음 스테이지로, 메뉴의 R은 현재 스테이지 시작으로 이동합니다.

구현: [StageModel.java](../core/src/main/java/io/jbnu/test/StageModel.java). 검사: `python tools/model_test.py` 또는 `gradlew.bat core:check`.
